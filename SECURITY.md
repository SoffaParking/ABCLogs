# Security policy

The Soffa API Logs Dashboard stores request metadata and error logs, which can
contain sensitive information, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability
reporting instead: on the repository, go to **Security → Report a
vulnerability**.

Include what you found, how to reproduce it, and the impact you expect. You
will get an acknowledgement within a few days. Fixes are released as soon as
practical, and reporters are credited unless they prefer otherwise.

## Supported versions

Until 1.0, only the latest release receives security fixes.
